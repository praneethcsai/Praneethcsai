### 🚀 Featured Projects

> Built during my work at **Inventzo Systems (Jun 2022 – Present)**. Source code is proprietary; these write-ups describe architecture, my contributions, and the tech used.

#### 🧩 Story-Assist — SDLC Automation & Jira Integration
An automated tool that streamlines the software development lifecycle by bulk-creating and linking Jira stories to Epics/Features.
- Built backend services in **Python + FastAPI** (served via Uvicorn) with robust error handling and SSO integration
- Designed a custom **version-control system for user stories** with state management and rollback
- Integrated a **RAG pipeline** to auto-generate stories, acceptance criteria, and task descriptions from historical Jira data
- Added **vector-DB semantic search** over past stories for reuse, consistency, and accuracy
- Trained ML models for requirement analysis, story classification, and effort estimation

`Python` `FastAPI` `PostgreSQL` `RAG` `Vector DB` `LLMs` `AWS`

#### 📊 Database Access Management (DAM) — Auditing & Anomaly Detection
A monitoring platform that captures every SQL query, access event, and user action across multiple databases.
- Built **AI-driven real-time dashboards** with Dash, Plotly, and Panel for monitoring and decision support
- Trained **scikit-learn** models for event classification and anomaly detection on historical + live query streams
- Engineered automated data-cleaning/labeling pipelines with Pandas & NumPy
- Added a **RAG framework** for natural-language querying of audit logs, plus vector search over query/access patterns
- Validated pipelines and dashboard APIs with **pytest** test suites

`Python` `scikit-learn` `Plotly` `Dash` `RAG` `Vector DB` `pytest`

#### 🔐 Network Discovery Tool & Password Masking App
A multi-threaded engine to scan and monitor active servers, IPs, and network resources in real time.
- Built a **multi-threaded discovery engine** with socket-based communication for host/network metadata
- Implemented **secure password masking & encryption** using industry-standard cryptographic libraries
- Developed the **Password Mask Lite browser extension** for secure credential handling and auto form-fill
- Deployed scalable backend services and cloud-hosted databases on **GCP**

`Python` `Multithreading` `Cryptography` `GCP` `Browser Extensions` `Networking`
